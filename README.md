# hifi-mobiNet

Local release preparation for the HiFi-GAN ResBlock2, Parallel-IR and
Sequential-IR speech synthesis systems developed in BanhmiTTS, with Piper
as an external checkpoint reference. This repository is a new organization
of existing code and evidence, not a recovered training-time Git history.

Implementation is in progress. See [implementation status](docs/implementation-status.md)
and [release gaps](docs/release-gaps.md). No remote or deployment is configured.

No repository-wide license has been selected. Upstream rights and notices
must be retained; author permission and model/audio redistribution remain
separate release decisions.
